# 陪玩点单平台 · 微信小程序原型设计说明

> **版本**：v1.0（2026-11-26，Figma AI 输入版；业务规则以《产品需求.md》2026-11-26 版为准，本文只描述界面与交互）
> **范围**：微信小程序 C 端（游客 / 老板 / 陪玩），竖屏移动端，Frame 基准 375×812；不含管理后台界面。
> **标记约定**：
> - 【占位框】＝细节尚未定稿，原型中画整体空白占位框、框内标注待补内容，不阻塞主流程页面；
> - 页面编号 P01–P28，弹窗/浮层编号 M01–M10，流程编号 F1–F5，可直接作为 Figma Frame 命名。

## 三、全局框架与通用组件

### 3.1 底部 Tab 与悬浮按钮

| 序号 | Tab | 内容 |
|---|---|---|
| 1 | 首页 | 播报、活动、板块 |
| 2 | 陪玩 | 陪玩列表、排行榜入口、悬浮派单按钮 |
| 3 | 会话 | IM 私聊、客服、系统消息、派单与绑定消息 |
| 4 | 我的 | 主页、钱包、订单、设置 |

**公开派单悬浮按钮**：位于「陪玩」Tab 屏幕右侧，可上下拖动、不遮挡核心操作；老板点击进 P10-A；游客点击弹 M08 登录引导；陪玩身份下隐藏。

### 3.2 顶部通用区

- **首页顶部**：搜索框、排行榜入口、送礼播报滚动区；**无通知图标**（通知在会话 Tab 的系统消息会话内）。
- **陪玩列表顶部**：搜索框、头牌榜前三头像 +「点击查看完整榜单」。
- 二级页返回键与标题栏：【占位框：统一导航栏规范】。

### 3.3 全局组件（建议建为 Component）

| 组件 | 变体/状态与内容 |
|---|---|
| 陪玩卡片 | 在线 / 离线（离线置灰）；头像、昵称、性别、年龄、板块、等级、简介、语音试听按钮（仿微信语音消息样式） |
| 板块 Tag / 等级 Tag | 正常 / 被取消（取消后不可接单，可不做视觉态） |
| 榜单条目 | 普通 / 前三样式；公开 / 匿名 / 金额隐藏三态 |
| 礼物图标 | 已收到点亮（显数量、送礼人数）/ 未收到灰色 |
| 星星金额文本 | 统一代币标识，整数显示 |
| 订单状态标签 | 六态：待开始/服务中/待确认/已完成/已评价/已退款 |
| 主按钮 / 次按钮 / 禁用按钮 | 【占位框：视觉规范】 |
| 倒计时组件 | 派单 120s 窗口、支付等待等 |
| 空状态 / 加载 / 错误重试页 | 统一组件，插画与文案【占位框】，见 3.5 |

### 3.4 弹窗 / 浮层 / 抽屉清单

| 编号 | 名称 | 类型 | 触发时机 | 界面要点 |
|---|---|---|---|---|
| M01 | 点单须知弹窗 | 半屏/全屏弹窗 | 付款前 | 先总须知后板块须知；须滑到底部「我已悉知」按钮才点亮 |
| M02 | 礼物弹窗 | 底部抽屉 | 点送礼/打赏 | 单种礼物、数量可多个、余额不足引导充值 |
| M03 | 收银台 | 弹窗或页面 | 结算后 | 仅星星余额支付；余额不足引导充值 |
| M04 | 派单应单提醒 | 会话 Tab 的 IM 消息（非弹窗） | 符合条件的派单发布 | 接受/拒绝；消息留痕可回看，错过后回小程序可补查 |
| M05 | 取消订单确认 | 二次确认弹窗 | 开始前老板主动取消 | 提示原路退星星 |
| M06 | 超时未开始选择 | 对话框 | 等待超时 | 「继续等待（重置计时）/ 退款」二选一 |
| M07 | 评价 | 弹窗或页面 | 订单完成 | 星级 + 文字 + 匿名开关；默认 5 星 |
| M08 | 登录引导 | 弹窗 | 游客触发受限操作 | 微信登录 / 短信登录两入口 |
| M09 | 注销确认 | 强确认弹窗 | 申请注销 | 明示余额作废、数据留存范围、前置条件校验 |
| M10 | 全局 Toast | 轻提示 | 操作反馈 | 【占位框：文案库】 |

### 3.5 通用状态页

| 状态 | 出现位置 | 画面要点 |
|---|---|---|
| 加载中 | 所有列表/详情 | 骨架屏或 Loading，样式【占位框】 |
| 空列表 | 订单、流水、送礼记录、应单列表、搜索无结果 | 插画 + 文案 + 是否带按钮【占位框】 |
| 网络错误 | 全页面 | 错误提示 + 重试 |
| 余额不足 | 支付/送礼 | 提示文案 +「去充值」跳转 |
| 权限拦截 | 陪玩点单入口、游客受限操作 | 提示文案 |
| 派单超时 | 派单等待页 | 失效态 +「重新发起」 |

## 四、页面线框说明

### P01 登录页

- **页面目标**：微信快捷登录或短信验证码登录；游客可跳过。
- **入口**：启动小程序；M08 登录引导。
- **线框区块**：
  1. 品牌区：Logo、Slogan【占位框】；
  2. 微信快捷登录主按钮；
  3. 短信登录入口 → 展开手机号输入 + 验证码输入 +「获取验证码」（倒计时秒数【占位框】）；
  4. 用户协议/隐私政策勾选，未勾选不可登录，协议文本【占位框】；
  5. 「随便看看」游客模式入口。
- **交互跳转**：登录成功回到来源页。
- **状态异常**：验证码错误/过期、网络异常、拒绝微信授权。

### P02 首页

- **页面目标**：内容分发与功能集散。
- **入口**：底部 Tab 1。
- **线框区块（自上而下）**：
  1. 顶部栏：搜索框（→P06）、排行榜入口图标；无通知图标；
  2. 系统播报滚动区：仅送礼播报轮播，金额不脱敏；滚动样式【占位框】；
  3. 活动 Banner 区：多活动自动轮播（→P04）；
  4. 营业板块卡片区：板块名 + 图标（→P03），排布列数【占位框】；
  5. 不放推荐陪玩/头牌等其他区块。
- **状态异常**：无活动/无板块空态。

### P03 板块详情页

- **页面目标**：展示须知、价格、加价目录与本板块陪玩。
- **入口**：首页板块卡片。
- **线框区块**：
  1. 板块标题区；
  2. 分段 Tab：总点单须知 / 板块点单须知 / 价格表 / 加价项目录；
  3. 须知长文本（仅浏览，正式知悉发生在 M01）；
  4. 价格表：按「等级 × 模式」展示单价（星星/小时、星星/局），表格或卡片样式【占位框】；
  5. 加价项目录：加价项名称 + 固定金额；
  6. 本板块陪玩列表：下拉分页加载、默认随机排序，卡片样式同 P05，点击进 P08；是否复用 P05 筛选/排序控件【占位框】。

### P04 活动详情页

- **线框区块**：
  1. 活动 Banner 大图；
  2. 活动标题、起止时间、状态标识（进行中/已结束）；
  3. 富文本正文：活动介绍、规则与参与方式；
  4. **纯展示、无「参与」按钮**（参与资格由后台自动判定，C 端不表达）。
- **状态异常**：过期活动自动下架、不可进入；历史活动列表【占位框】。

### P05 陪玩列表页

- **页面目标**：浏览、排序、筛选全店陪玩。
- **入口**：底部 Tab 2。
- **线框区块（自上而下）**：
  1. 顶部搜索框（→P06）；
  2. 头牌榜前三头像区 +「点击查看完整榜单」（→P07）；
  3. 排序栏：默认「随机」，可切换优质/热门/新人；
  4. 筛选入口 → 筛选抽屉：板块、性别、级别、在线状态、音色五维度，可多选/组合，带「重置/确定」；
  5. 陪玩卡片列表：分页加载、下拉刷新；离线陪玩卡片置灰；
  6. 卡片点击 → P08；卡片快捷下单按钮【占位框】；
  7. 右侧悬浮「公开派单」按钮（→P10-A）。
- **交互规则**：先筛选过滤再按排序展示；筛选条件回填、已选标签展示；列表单列/双列【占位框：两种布局候选待确认】。
- **状态异常**：筛选无结果空态。

### P06 搜索页 / 搜索结果页

- **入口**：首页、陪玩列表顶部搜索框。
- **线框区块**：
  1. 搜索输入框（昵称模糊、系统 ID 精确）+ 取消；
  2. 未输入态：无搜索历史、无热门搜索；
  3. 结果态：用户结果混合列表，带陪玩/老板标识、不设角色分 Tab；点击分别跳 P08 / P17；结果卡片字段【占位框】；
  4. 无结果态：提示文案（重名靠头像与 ID 辨别）。
- **界面规则**：隐私号老板不出现在结果中；陪玩始终可被搜索。

### P07 排行榜页

- **入口**：首页排行榜图标；陪玩列表顶部「查看完整榜单」。
- **线框区块**：
  1. 周期切换：日榜/周榜/月榜（无小时榜）；
  2. 榜单类型 Tab：头牌陪玩榜 / 老板消费榜 / 亲密度榜；
  3. 前三领奖台：大头像、名次、昵称、数值，风格【占位框】；
  4. 第 4–10 名条目：排名、头像、昵称、流水/消费/亲密度值；
  5. 隐私态：金额隐藏显示「-」；匿名显示默认文案"老板"；亲密度匿名同理；
  6. 榜单隐私设置入口（→P19 或本页浮层）。
- **交互跳转**：陪玩条目 →P08；老板条目 →P17；前端定时拉取、不做推送。
- **状态异常**：榜单未生成/数据为空；并列名次视觉处理【占位框】。

### P08 陪玩详情页

- **页面目标**：全面了解陪玩并发起试听、下单、打赏、举报。
- **入口**：陪玩卡片、排行榜、搜索结果、会话头像。
- **线框区块（自上而下，固定排序不可拖拽）**：
  1. 顶部背景图 + 返回/更多（「更多」菜单含举报，点击拉起 P16 客服会话）；
  2. 头像、昵称、性别、年龄、在线状态；
  3. Tag 区：板块 Tag、等级 Tag（不可自改，取消后硬拦截接单）；
  4. 个性签名/个人介绍；
  5. 恋爱状态条：单身/恋爱中；匿名绑定时仅显示「恋爱中」；
  6. 语音试听条：播放/暂停、时长，仿微信语音消息；
  7. 礼物墙：全部礼物图标网格，已收到点亮并显示数量与送礼人数，未收到灰色；不展示送礼人；
  8. 评价区：评分汇总【占位框：是否做评分均分】+ 评价条目（星级、文字、匿名/公开昵称、时间），分页；
  9. 底部固定操作栏：「下单」（→P09）、「打赏」（→M02）。
- **状态异常**：陪玩 Tag 被取消时，下单入口拦截提示。

### P09 指定单下单页

- **页面目标**：选好陪玩后填写需求并完成支付前全部配置；交互类似"加入购物车"，可累加多人。
- **入口**：P08「下单」、列表卡片快捷入口。
- **线框区块（自上而下）**：
  1. 已选陪玩区：头像 + 简短自我介绍，可移除/继续添加（→P05）；
  2. 板块选择（按已选人数分态）：
     - 仅 1 名陪玩：可改板块，候选项仅该陪玩已认证的板块；
     - 2 名及以上：板块锁定、选择器置灰，提示"多陪玩下单不可更改板块"；
     - 未选陪玩：可自由选择；
  3. 陪玩类型区（置灰仅展示）：性别（男/女/不限）、等级（娱乐/技术/优技/顶技/PRO/不限）；
  4. 模式选择：取当前板块的模式字典（例：匹配/娱乐模式/趣味单/排位各段位）；
  5. 计价类型与数量：按小时或按局；数量步进器 ≥1，实时显示「单价 × 数量」；
  6. 加价项多选区：固定金额、可叠加；「一陪多」附带数量选择，仅标签不核查人数；
  7. 预约时段：开始/结束时间，精度年月日时分，跨度最少 1 小时；可不选表示立即；按局计价时是否校验最小跨度【占位框】；
  8. 备注输入框；
  9. 底部结算栏：每陪玩金额明细 + 加价合计 + 总价（星星）+「下单」。
- **交互跳转**：下单 → M01 须知 → P11；多陪玩 UI 合并为一组，底层生成 N 条独立订单。
- **状态异常**：某陪玩 Tag 被取消时拦截提示；余额不足在 P11 处理。

### P10 公开派单：发布页 + 等待页

#### P10-A 派单发布页
- **入口**：P05 右侧悬浮按钮。
- **线框区块**：
  1. 游戏板块选择；
  2. 陪玩类型：期望性别、期望等级（含"不限"）；
  3. 模式选择（按板块字典联动）；
  4. 需求备注；
  5. 预估价格区：随填写实时刷新预估星星金额；
  6. 「发布派单」按钮 → P10-B。

#### P10-B 派单等待页
- **线框区块**：
  1. 顶部倒计时：默认 120s，环形或进度样式；
  2. 应单陪玩实时列表：卡片同 P05，随应单实时插入，**按陪玩响应时间先后排序**，每个卡片带「加入下单」多选；
  3. 已选人数/已添加清单（可移除）；
  4. 底部「下单（n）」→ P11（回填板块/类型/模式/陪玩/总价）；
  5. 老板可主动提前结束窗口（按钮文案与位置【占位框】）；
  6. 超时态：派单失效提示 +「重新发起」。
- **界面规则**：未被选中的应单自动失效、无消息提醒；客服代发链接打开后落到同一等待页。

### P11 结算与支付页

- **入口**：P09/P10 知悉 M01 后。

### P13 订单详情页

- **页面目标**：承载订单全生命周期操作与状态时间线。
- **线框区块**：
  1. 顶部状态标签 + 状态说明；
  2. 双方信息卡：老板/陪玩头像昵称，「联系对方」→P16；
  3. 服务信息：板块、模式、等级、计价类型、数量、预约时段、备注；
  4. 费用明细：单价快照、加价明细、退款记录；陪玩侧仅展示抽佣后净得星星数；
  5. 状态时间线：付款 → 开始 → 结束 → 确认 → 评价/退款，逐节点时间（节点文案【占位框】）；
  6. 底部操作区（按状态与角色切换）：

| 状态 | 老板侧按钮 | 陪玩侧按钮 |

| 待开始 | 取消订单（M05）；超时后弹 M06（等待/退款） | 开始服务、拒绝服务（全额退款） |

### P14 评价页（或 M07 弹窗）

### P21 充值页

- **入口**：钱包充值、支付/送礼余额不足引导。
- **线框区块**：

  2. 自定义金额输入，输入后按当前汇率实时折算到账星星；
  3. 支付说明：调起微信虚拟支付收银台；
  4. 充值记录入口（金额、汇率快照、星星数、通道订单号、状态）；
  5. 回调态：成功入账 / 待支付 / 已关闭；

## 五、核心流程的页面串联（供 Prototype 连线）

### F1 指定单下单（含多陪玩）

```
P05/P08 选陪玩（可多人，购物车式）
  → P09 填需求（板块/模式/加价/数量/预约/备注）
  → M01 须知弹窗（滑到底 → 我已悉知）
  → P11 结算支付（星星余额）
       ├─ 余额不足 → 引导 P21 充值 → 返回 P11 重付
       └─ 支付成功 → 结果页（一组订单入口）→ P13
            ├─ 开始前：老板 M05 取消 / 陪玩拒绝 / 超时 M06 → 已退款
            └─ 陪玩开始(P27) → 服务中 → 陪玩结束 → 待确认
                 ├─ 老板确认 / 超期自动确认 → 已完成
                 └─ P14 评价（超期自动 5 星）→ 已评价
```

### F2 公开派单 / 客服派单

```
P05 悬浮按钮 → P10-A 发布（预估价实时刷新；可提前结束窗口）
  → P10-B 120s 等待（陪玩端会话 Tab 收 IM 派单消息 → 接受后进应单列表，按响应时间排序）
       ├─ 超时无人应单 → 失效 → 重新发起
       └─ 老板选人（可多个）→ P11 回填 → M01 → 支付 →（同 F1 后半段）

客服派单：P16 客服会话 → 客服代发链接 → 打开 P10-B →（同上）
未被选中的应单：自动失效、无提醒；派单消息可回看
```

### F3 送礼

```
P08/P15 入口 → M02 选礼物（一种、数量多个）
  → 余额校验（不足 → P21）→ 赠送成功 + 全屏特效
  → 首页播报滚动 + 礼物墙更新 + 亲密度增加
  → 退款场景连带扣减亲密度（下限 0）
```

### F4 充值与提现

```
充值：P20/P11/P15 → P21 选档位或自定义金额 → 微信收银台 → 回调入账 → 充值记录
提现：P20 收入余额 → P22 选方式（微信零钱/银行卡）→ 后台审核
        ├─ 通过 → 打款 → 已到账
        └─ 驳回 → 星星回冲 + 原因展示
```

### F5 注册登录与注销

```
启动 → P01（游客可跳过）→ 微信/短信登录
注销：P25 → 前置校验（无进行中订单/收入已提现）→ M09 明示余额作废 → 提交即生效
```
